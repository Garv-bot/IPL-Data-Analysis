IPL Match Data Analysis

## Overview
This project analyzes IPL match data to uncover trends in match outcomes, team performance, and toss strategies.

## Tools Used
- Python
- Pandas
- Matplotlib
- MySQL
- Jupyter Notebook

## Key Insights
- Toss has negligible impact (~50%)
- Teams prefer chasing (~64%)
- Fielding first has higher success (~53%)
- CSK and MI are most consistent teams

## Files
- matches.csv → raw dataset
- cleaned_matches.csv → processed data
- IPL_Analysis.ipynb → analysis notebook
- clean_data.py → data cleaning script
