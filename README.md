# IPL Match Data Analysis

## 📌 Overview
This project analyzes IPL match data to understand trends in team performance, toss impact, and match strategies.

## ⚙️ Tools Used
- Python
- Pandas
- Matplotlib
- MySQL
- Jupyter Notebook

## 🧹 Data Cleaning
- Removed unnecessary columns
- Handled missing values
- Fixed season format (2007/08 → 2007)
- Converted date to proper format
- Standardized team names

## 📊 Analysis Performed
- Matches per season
- Toss impact analysis
- Bat vs Field decision impact
- Team performance analysis
- Win percentage calculation

## 📈 Key Insights
- Toss has negligible impact (~50%)
- Teams prefer chasing (~64%)
- Fielding first wins more (~53%)
- CSK & MI are most consistent teams
- Small sample teams give misleading results

## 📁 Project Files
- IPL_Analysis.ipynb → Main notebook
- matches.csv → Raw dataset
- cleaned_matches.csv → Cleaned dataset
- clean_data.py → Data cleaning script
